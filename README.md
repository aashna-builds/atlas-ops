# hugelopsguru

AI skills for Hugel U.S. operations and logistics. One plugin: **hugel-ops-ai-kit**.

| Skill | What it does |
| --- | --- |
| `rfp-builder` | Drafts a complete vendor RFP — scope, numbered requirements, vendor questions, pricing table, timeline, weighted criteria. |
| `rfp-response-evaluator` | Compares vendor responses, normalizes pricing, scores against the RFP's criteria, flags gaps and drafts follow-up questions. |
| `program-status` | Status reports (Green/Yellow/Red) and a RAID log for launches and integrations. |
| `vendor-performance` | Scorecards, QBR prep, and escalation drafts for vendors under contract. |
| `sop-builder` | Drafts and reviews ops SOPs and checklists; flags controlled-process steps for Quality/Regulatory review. |
| `training-builder` | Training guides, job aids, and onboarding plans. |

Each skill explains itself on first use, asks before producing anything and before delivering a document, and never sends anything externally.

## Install

- **Cowork:** Customize → Plugins → Add marketplace → enter `aashna-builds/hugelopsguru` → install **hugel-ops-ai-kit**.
- **Claude Code:** `/plugin marketplace add aashna-builds/hugelopsguru` then `/plugin install hugel-ops-ai-kit@hugelopsguru`.
